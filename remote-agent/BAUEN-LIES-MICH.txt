FERNWARTUNG – FERTIGE PROGRAMME BAUEN
=====================================

EMPFOHLEN: AUTOMATISCH IN DER GITHUB-CLOUD
  Jede Aenderung im Ordner remote-agent/ , die nach "main" gepusht wird, baut
  automatisch (kein eigener Windows/Mac noetig) und veroeffentlicht:

    • "⭐ Neueste Version"  – zeigt immer den aktuellsten Build (feste Download-Links).
    • "Version N"           – eine neue, fortlaufend nummerierte Version (1, 2, 3 …).
                              Alte Versionen bleiben dauerhaft erhalten.

  Dateien pro Release:
    • AlexReviewit-Schnellhilfe.exe        (Windows, QuickSupport, keine Installation)
    • AlexReviewit-Fernwartung-Setup.exe   (Windows, Vollversion – Installer)
    • AlexReviewit-Schnellhilfe.pkg        (macOS, QuickSupport)
    • AlexReviewit-Fernwartung.pkg         (macOS, Vollversion – Installer)
    • version.json                         (steuert das automatische Update)

  Die Versionsnummer wird beim Bauen in build.txt geschrieben und ins Programm
  gepackt, damit das automatische Update sie vergleichen kann. Der Windows-Installer
  wird mit Inno Setup aus Fernwartung.iss gebaut. Nichts davon muss man von Hand
  anpassen – es laeuft bei jedem Push.

  Manuell anstossen: GitHub -> Reiter "Actions" -> "Build Fernwartung" -> "Run workflow".

LOKAL BAUEN (optional)
  • Windows:  Doppelklick auf  BUILD-Windows.cmd
  • macOS:    Doppelklick auf  BUILD-Mac.command
  Ergebnis liegt im Ordner "fertig" bzw. "dist".

OHNE FERTIGE DATEI (nur zum Testen, braucht Python 3)
  • Schnellhilfe:    SCHNELLHILFE-Windows.cmd  /  SCHNELLHILFE-Mac.command
  • Geraet einrichten: GERAET-EINRICHTEN-Windows.cmd  /  GERAET-EINRICHTEN-Mac.command

AUFBAU (welche Datei macht was)
  • agent.py           – die ganze Logik (Signaling, Bildschirm, Steuerung, Fenster,
                         automatisches Update, Passwort-Modi)
  • _startguard.py     – faengt Startfehler ab und zeigt/protokolliert sie
  • schnellhilfe.py    – Einstieg Schnellhilfe (QuickSupport)
  • vollversion.py     – Einstieg Vollversion (Host)
  • Fernwartung.iss    – Windows-Installer (Inno Setup)
  • version.json       – Vorlage fuer das Update (die Nummer setzt die CI)
  • .github/workflows/build-fernwartung.yml – baut & veroeffentlicht automatisch

SIGNATUR / WARNUNGEN
  • Windows SmartScreen zeigt bei unsignierten Dateien "Unbekannter Herausgeber"
    (mit Code-Signing-Zertifikat behebbar, optional).
  • macOS Gatekeeper blockiert unsignierte Apps: Rechtsklick -> "Oeffnen",
    oder sauber per Apple Developer ID signieren und notarisieren.

GROESSE: ~70–150 MB pro Datei (Python + WebRTC/FFmpeg sind mit eingepackt).
